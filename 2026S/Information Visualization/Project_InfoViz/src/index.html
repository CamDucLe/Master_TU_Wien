About the Project

Project Overview

This dashboard is an interactive Information Visualization system designed to explore the drivers of success in the Steam gaming market. By providing seven dynamic, coordinated visualization panels (including price scatter plots, genre price-tier heatmaps, release timelines, tag clusters, and business model comparisons), the tool enables users to uncover how price, genre, player engagement, and reception influence a game's market viability.

How Success is Measured

Rather than using a static definition of success, the dashboard implements a customizable success score that combines three core dimensions:

  • Ownership: The estimated owner count of the game (log-normalized to handle the scale difference between small indie projects and viral hits).
  • Reception: The ratio of positive user reviews, smoothed using a phantom-review method so that games with very few reviews do not skew findings.
  • Engagement: The median playtime recorded for the game's users (log-normalized).

Success Score = (α × Ownership + β × Review Ratio + γ × Playtime) / (α + β + γ)

Adjusting the weights (α, β, γ) in the weights card dynamically updates the success scores of all games and immediately refreshes every visualization across the dashboard.

Educational Context

This project was developed for the Information Visualization (VU) course in the 2026S semester at the TU Wien (Vienna University of Technology).

Aligned with the academic curriculum, the application focuses on demonstrating advanced visualization principles: multiple coordinated views (MCV), interactive brushing and linking, clean and distinguishable visual encodings, and robust preprocessing of real-world datasets.
