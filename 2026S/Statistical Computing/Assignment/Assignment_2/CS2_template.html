Function definition

As the format of 2 files rawdata_369.txt and rawdata_347.txt are quite similar then we decide to define a function that read content of 2 files line by line consider each line as a small dataframes. After that, we bind them together to form a single datframe which has 2 columns: country and a respective variable. Note: we split each line on 2 or more consecutive whitespace characters to get the values based on the provided guidelines.

library(dplyr)
library(readr)
library(tidyr)
library(readxl)

read_txt_to_df <- function(file_path, col_name){
  # Read line by line, [-(1:2)] removes the first 2 lines
  lines <- readLines(file_path)[-(1:2)]

  # Remove empty trimmed line
  lines <- lines[nchar(trimws(lines)) > 0]

  # Split each line on 2 or more consecutive whitespace characters
  split_lines <- strsplit(lines, "\\s{2,}")

  # Create a list of named character vectors
  rows <- lapply(
    split_lines,
    function(row) {
      df <- data.frame(
        country = row[2],
        value = row[3],
        stringsAsFactors = FALSE
      )
      return(df)
    }
  )

  # Bind them together to create a dataframe
  rows_list <- bind_rows(rows)

  # Type cast and keep only necessary columns (tibble)
  df <- rows_list %>%
    mutate(
      country = trimws(country),
      !!col_name := as.numeric(value),
      .keep = "none",
    )

  return(df)
}

c. Enriching Data with Income Classification

Obtain country income classification (low, lower-middle, upper-middle, high) from the World Bank and merge it with the dataset.

Solution description

Both our merged dataset and the World Bank data contain country names, so this is the common variable. However, country names cannot be reliably used for merging because different sources use different naming conventions (e.g., “Turkey” in our data vs. “Türkiye” in the World Bank data, “Macedonia” vs. “North Macedonia”, “Korea, South” vs. “Korea, Rep.”, etc.). Even small discrepancies in spelling, punctuation or formatting would cause observations to be lost.

Instead, we use standardised ISO 3-letter country codes as a bridge. The CIA Country Data Codes file maps CIA country names (which match our data) to GENC/ISO codes, and the World Bank data contains ISO3 codes — so we can join the two on that shared, unambiguous key.

We also manually impute country code for some countries as their names are presented differently in data file from Word Bank.

Simpson’s Paradox can occur here because the composition of continents differs between income groups. For instance, low-income countries are overwhelmingly located in Africa, where youth unemployment may be measured differently or where informal employment is common (leading to lower reported unemployment). High-income countries are concentrated in Europe, where youth unemployment can be notably high (e.g., Southern Europe). Overall, low-income countries may appear to have lower youth unemployment than high-income countries, but within any given continent where both groups coexist, the relationship may reverse. The paradox arises because continent acts as a confounding variable — it is associated with both income level and unemployment patterns.
