# CLEF2026--CheckThat-Lab
This repository will contain the _dataset_, _format checker, scorer and baselines_ for each task of the [CLEF2026-CheckThat! Lab](https://checkthat.gitlab.io/).

The **2026 edition** of the lab focuses on tasks that are at the core of the verification pipeline as well as auxiliary tasks:
  - [Task 1 Source Retrieval for Scientific Web Claims](task1)
  - [Task 2 Fact-Checking Numerical and Temporal Claims](task2)
  - [Task 3: Generating Full-Fact-Checking Articles](task3)

Details will be available soon. Stay tuned!
